# Rafi 2.0.4 — согласованные исправления

Основа: Rafi 2.0.3. Изменён только `src/main/resources/static/index.html`. Java, настройки, структура базы данных и существующие цвета светлой темы сохранены.

1. Удалён дублирующий пункт смены темы в мобильном меню; верхний переключатель сохранён.
2. Декоративные рамки элементов заменены лёгкими тенями и контрастом поверхностей.
3. Тёмная тема сделана графитово-чёрной с сохранением персиковых акцентов.
4. Схема зон ограничена шириной мобильного контейнера.
5. Убран синий touch-highlight при нажатии на логотип, сохранена доступная клавиатурная фокусировка.
6. Разработчику открыт календарь и переход на него в нижней навигации.
7. Для разработчика календарь и карточка банкета работают в режиме просмотра: скрыты элементы изменения банкетов. Серверные права доступа не изменены.
8. Для удаления клубов и позиций каталога обработчик гарантированно снимает disabled в блоке finally; поведение последовательных удалений нужно дополнительно проверить в браузере.
9. Нижняя мобильная навигация разделена по ролям; дублирующие пункты убраны из меню «Ещё», поиск перенесён в нижнюю панель администратора.
10. Добавлена карточка текущего пользователя внизу мобильного меню с раскрывающимися пунктами смены пароля и выхода.
11. На телефоне вместо пустой круглой кнопки статуса теперь компактный подписанный выпадающий список, добавлен статус «Перенесённые».

**Перед обновлением:** сохраните копию рабочей версии и папку `data`; переменные `RAFI_DEVELOPER_PASSWORD` и `RAFI_ADMIN_PASSWORD` должны быть заданы в конфигурации запуска, если требуются при инициализации учётных записей.

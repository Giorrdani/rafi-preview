# Rafi 2.0.3 — мобильная шапка

Основа: Rafi 2.0.2. Без изменений Java и структуры БД.

- Выбор клуба на телефоне: название и стрелка без рамки; собственное выпадающее меню, синхронизированное с исходным select.
- Размер названия клуба не изменён (12px).
- Шрифт поиска увеличен до 14–16px.
- Стрелка поиска заменена на центрированный SVG внутри круглой кнопки в поле.
- Переключатель светлой/тёмной темы в мобильной шапке, использует прежний механизм и сохранение в localStorage.
- Сохранена вся серверная логика и база данных.

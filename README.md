# Rafi — визуальная демонстрация

Статическая копия актуального интерфейса с тремя темами: Фарфор, Графит, Изумруд. Все имена, телефоны, банкеты и показатели вымышлены. Java, сервер и база данных не нужны.

## Публикация на GitHub Pages

1. Создайте отдельный репозиторий для демонстрации.
2. Загрузите **содержимое этой папки** в корень репозитория, включая `.nojekyll`. Файл `index.html` должен лежать в корне.
3. Откройте Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Откройте адрес, который покажет GitHub Pages.

## Проверка

В верхней полосе выберите роль: администратор, управляющий или разработчик. Тема переключается штатной кнопкой приложения. Проверьте календарь, карточку банкета, меню, услуги, схему, статистику и менеджер клубов на компьютере и телефоне.

Примеры банкетов привязаны к текущему месяцу. Нажмите сегодняшнюю дату, чтобы открыть примеры. Создание и изменение демонстрационных банкетов действует только до перезагрузки страницы. Это упрощённая имитация для проверки вида форм; расчёты и бронирование мест не проверяют бизнес-правила настоящего приложения.

Изменения настроек, аккаунтов, клубов, загрузка файлов, публикация презентации, отправка сообщений, PDF и Excel отключены. Они требуют настоящего сервера. Презентация и рассылка показывают только формы. Демонстрация не защищена паролем: не вводите реальные персональные данные.

Можно также открыть `index.html` локально. Для максимально близкого к GitHub Pages поведения используйте любой локальный статический веб-сервер.

Рабочее приложение не изменено. В комплекте нет базы данных, пользовательских фотографий, паролей, конфигурации сервера и исполняемого JAR.

# Rafi 2.1.0-preview — новая тестовая версия

Готовое приложение находится в **dist/rafi.jar**. Исходники — в src. Java 21+, Spring Boot 3.5.6. Основной дизайн Rafi сохранён; изменения встроены в текущую оболочку.

## Как посмотреть
1. Распакуйте весь архив в отдельную папку. Не заменяйте им прежний проект.
2. Установите Java 21, если её нет.
3. Запустите **start.bat**. При первом запуске задайте пароли аккаунтов **developer** и **admin**. Минимум 8 символов, максимум 72 байта UTF-8.
4. Откройте **http://localhost:8081**. Для остановки нажмите Ctrl+C в окне приложения.

Пароли не встроены в архив и не записываются в файл. Первый запуск создаёт отдельную локальную базу data/kidsclub.mv.db. По умолчанию приложение доступно только с этого компьютера. Если порт 8081 занят, остановите прежний локальный экземпляр или запустите JAR с параметром --server.port=8082 и откройте выбранный порт.

Прямой запуск: задайте RAFI_DEVELOPER_PASSWORD и RAFI_ADMIN_PASSWORD в окружении первого процесса, затем выполните `java -jar dist/rafi.jar --server.address=127.0.0.1` из папки версии. Для существующей базы эти переменные не нужны.

## С чего начать
- Под developer: «Менеджер клубов» → создание клуба; «Информация и схема клуба» → сведения, расписание, стулья, фон, типы столов и сами столы. Стол можно отнести к постоянной зоне или оставить отдельным. Для нового клуба сначала создайте типы и столы.
- Под developer: «Аккаунты и филиалы» → создание владельца и администраторов с доступом к выбранным филиалам.
- Под admin: меню и услуги → наполните каталог; затем «Новый банкет». Заполняйте карточку постепенно. Данные сохраняются автоматически; ошибки видны сверху. Столы резервируются после задания полного интервала, гостей и рассадки.
- После заполнения важных разделов нажмите «Подтвердить банкет». Меню и услуги в режиме просмотра свёрнуты. Изменение времени, гостей или рассадки подтверждённой брони применяется явно после просмотра результата; суммы и состав заказа сохраняются автоматически.
- Под владельцем: доступны рабочие функции администратора, статистика выбранного филиала и сотрудники. Переключение филиала находится в общей шапке.
- На телефоне тема находится в меню аккаунта.

## Рассадка
Для 1–4 гостей при наличии подходящего свободного отдельного стола выбирается он; «Закрепить выбранную зону» сохраняет специальный выбор. При расширении банкета используются сначала близкие, затем дальние свободные столы. Они остаются на своих местах и подсвечиваются вместе. Стол целиком занят одной бронью, даже если мест больше, чем гостей. Стулья проверяются по пиковому одновременному использованию.

При первом обновлении существующие зоны получают первоначальные столы на 14 мест. **Это начальная настройка для тестирования: разработчик должен сверить вместимость, запас стульев и расположение с конкретным клубом.** Исходный фон загружается отдельно. Архив не содержит схем и базы прежнего проекта.

## Данные и обновление
Прежняя папка rafi-improved не изменена. В новой версии старые тестовые суммы аренды обнуляются; меню и услуги становятся единственным источником стоимости. Контактные заявки переносятся в единую карточку. Старые брони и их занятость сохраняются при обновлении, но новую структуру следует сначала проверять на отдельной копии базы и каталога data/plans. **Не переносите рабочую базу без копии и проверки восстановления.**

Профиль PostgreSQL и миграция V3 приложены, но реальная PostgreSQL в этой работе не подключалась и миграция на ней не испытана. Для текущего просмотра используйте отдельную H2-базу по умолчанию.

## Сборка из исходников
Обычная среда с Java 21 и Maven: `mvn clean verify` или build.bat. В IntelliJ откройте pom.xml и выберите SDK 21. start.bat использует готовый JAR и Maven не требует.

В среде агента стандартному файловому менеджеру javac запрещено разрешать реальные пути доступных библиотек. Поэтому исходники скомпилированы Java 21 через адаптер файлового менеджера, затем отдельно выполнены Maven Surefire и упаковка Spring Boot. Это настоящая компиляция, тесты и исполняемый JAR, но не заявленный успешный запуск обычного `mvn clean verify` в этой среде. Подробности — verification/RESULTS.md.

## Проверки и границы версии
См. **verification/RESULTS.md**, **CHANGES-2.1.0-preview.md** и **docs/PRODUCT-DECISIONS-2.1.md**. Архив предназначен для локального знакомства и дальнейшей доработки, не для установки на рабочий сайт. Подписка, онлайн-платежи и приложения iOS/Android в него не входят. Фотоотчёт/phrep.ru не изменялся.

PDF использует системный шрифт Arial/DejaVu/Liberation; при необходимости задайте RAFI_PDF_FONT с путём к TTF, поддерживающему кириллицу. Журнал изменений фиксирует изменения карточек и предоплат; это не банковская система и не отдельный журнал платёжных транзакций.

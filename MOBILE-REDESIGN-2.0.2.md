# Rafi 2.0.2 — мобильный интерфейс по утверждённому изображению

Основа: Rafi 2.0 Peach & Slate (НЕ отменённая 2.0.1).

- На мобильном экране логотип и название клуба в одной строке, название без рамки.
- Поиск — реальное поле ввода с кнопкой-стрелкой внутри; Enter и стрелка запускают исходный поиск.
- Кнопка «Новый банкет» рядом с заголовком.
- Полный календарь месяца с округлёнными прямоугольными датами и цветными статусами.
- Бронирования дня в карточках; выбор даты и открытие банкета сохранены.
- Нижняя навигация: календарь, поиск, зоны, «Ещё». «Ещё» открывает существующее боковое меню и настройки аккаунта.
- Сохранены desktop CSS, Java-контроллеры, API и схема БД.

Важно: это реализация интерфейса по визуальному референсу, а не пиксельная копия изображения; реальные названия, бронирования, длина текста и размеры экранов могут отличаться. В данной среде проверен синтаксис JS; полноценный запуск Spring Boot и проверка в мобильном браузере не проводились.

При запуске первой установки укажите переменные RAFI_DEVELOPER_PASSWORD и RAFI_ADMIN_PASSWORD (минимум 10 символов). Перед переносом данных сохраните копию каталога data. Путь H2 относительно рабочей директории: ./data/kidsclub.

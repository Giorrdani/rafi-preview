# Rafi 2.0.5 — согласованные исправления

Основа: Rafi 2.0.4. Изменения ограничены согласованными пунктами. Java-модели, база данных, пароли и настройки темы не менялись.

1. Выпадающий список категорий каталога оформлен в стиле Rafi.
2. Новая категория создаётся через встроенное модальное окно вместо `prompt`.
3. Фильтр статусов оформлен как компактный выпадающий список.
4. Кнопки добавления категории и блюда уменьшены.
5. Поиск каталога оформлен как поле со стрелкой внутри.
6. Индикаторы выбора зон в форме банкета уменьшены; множественный выбор сохранён.
7. Для разработчика разрешено только чтение API бронирований (`GET`); изменение бронирований по-прежнему запрещено.
8. Добавлены мобильные отступы перед блоком ближайших банкетов.
9. Перенос не изменяет цвет банкета и не показывается отдельным статусом фильтра/легенды. Поле `moved` в базе сохранено.
10. Разработчик получает данные календаря при первом входе в десктопной версии.
11. Отметки банкетов отображаются в календаре разработчика.
12. Для разработчика оставлены календарь, количество банкетов в месяце и список банкетов выбранного дня; оперативные виджеты скрыты.
13. Разработчику доступно перелистывание месяцев для просмотра.
14. На существующей схеме клуба администратор выбирает дату календарём или стрелками, нажимает на зону и видит банкеты выбранного дня со временем, клиентом, продолжительностью и статусом. План помещения не заменён списком.
15. При загрузке календаря повторно запрашиваются настройки клуба; виджеты администратора учитывают актуальные значения настроек разработчика.

## Проверки

- Синтаксис JavaScript: `node --check` — успешно.
- Chromium (имитация API): старт разработчика, календарь, отметки, статистика и переход по месяцам — успешно.
- Chromium (имитация API): старт администратора, кастомный список категорий, окно создания категории, дата схемы и просмотр банкета зоны — успешно.
- Chromium (имитация API): два последовательных удаления позиции каталога вызывают два DELETE — успешно.
- Java: изменение AccessFilter ограничено одним условием GET; сборка Maven и интеграционные тесты с настоящей базой в этой среде не запускались.

**Перед запуском:** сделайте резервную копию папки `data` и конфигурации запуска. Для первой инициализации учётных записей проект может требовать переменные `RAFI_DEVELOPER_PASSWORD` и `RAFI_ADMIN_PASSWORD` (не менее 10 символов).

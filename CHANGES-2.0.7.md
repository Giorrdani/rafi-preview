# Rafi 2.0.7 — согласованные изменения

Исходная версия: Rafi 2.0.6. Сохранены бизнес-логика, структура H2, цвета Peach & Slate, шрифт Manrope и оформление календаря.

1. Верхняя панель ПК: двухстрочная компоновка, поиск со стрелкой внутри, выбор клуба справа, переключатель темы и кнопка банкета во второй строке.
2. Карточки клубов: упорядоченная сетка действий, единая высота и отдельное действие удаления.
3. Тёмная тема: улучшен контраст полей ввода в формах и карточках без изменения календаря.
4. Выбор зон: один небольшой переключатель на зону, сохраняющий существующую множественную логику чекбоксов.
5. Выбор времени: собственная панель часов и минут, исходное поле сохраняет значение для существующего кода.
6. Визуальная регрессия: CSS ограничен затронутыми областями, дублирующая галочка в выборе зон скрыта.
7. Минимум пароля: 8 символов при создании, изменении и первоначальной настройке учётных записей.
8. Профиль на компьютере: раскрытие действий внутри бокового меню вниз.
9. Поиск: крестик очистки при наличии введённого текста.
10. Мобильная тёмная тема: контраст и тень нижней панели навигации.
11. Выбор клуба: единый верхний селектор в шапке; административное действие «Выбрать клуб» в менеджере клубов оставлено, поскольку это отдельная операция управления.
12. Проверка: синтаксис JavaScript и целостность архива.

Рассылки SMS/WhatsApp не включены — отдельный будущий этап.

## Ограничения проверки
Проверка в работающем Spring Boot с реальными пользователями, БД H2 и на телефоне не выполнена. Перед заменой версии сохраните папку `data` и предыдущий архив.

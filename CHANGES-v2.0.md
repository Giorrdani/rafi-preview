# Rafi 2.0 — Peach & Slate

Визуальный редизайн на базе Rafi v1.0.6-security-branches.

- Новый светлый стиль Peach & Slate, Manrope (Google Fonts с системным запасным шрифтом), адаптированная тёмная тема.
- Месячный календарь с отдельными ячейками, цветными индикаторами статусов и выделением выбранной даты.
- Карточки событий справа от календаря; статистика расположена ниже календаря.
- Мобильная версия: полный месячный календарь и нижняя навигация с отдельным набором вкладок для администратора и разработчика.
- Все существующие действия с банкетами, зонами, меню, услугами и клубами продолжают использовать оригинальный JavaScript и серверные API.
- Серверный Java-код, конфигурация безопасности и схема БД не менялись.

## Обновление с v1.0.6

1. Сделайте резервную копию существующей папки `data/` (приложение должно быть остановлено).
2. Откройте `KidsClub-Manager` как Maven-проект в IntelliJ IDEA, SDK Java 21.
3. Если используете прежнюю базу, перенесите папку `data/` в каталог `KidsClub-Manager` новой версии **до запуска**.
4. Запустите `com.kidsclub.KidsClubApplication`, откройте http://localhost:8081 и обновите страницу (Ctrl+F5).
5. Проверьте в своей среде обе роли, добавление и редактирование бронирований, повторное удаление элементов, тёмную тему и мобильную навигацию.

**Важно:** архив намеренно не содержит вашу базу данных. Не заменяйте её пустой. Не размещайте папку `data/` в публичных архивах.

## Область изменений

Изменён только `src/main/resources/static/index.html`. Остальной исходный код перенесён из v1.0.6 без изменений.
